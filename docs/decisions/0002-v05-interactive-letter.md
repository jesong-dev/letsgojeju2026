# 0002. v0.5 인터랙티브 편지 구현

- 상태: 채택
- 결정일: 2026-07-31

## 맥락

v0.4까지의 프로젝트 기본 원칙은 순수 HTML/CSS와 작은 TypeScript 모듈이었다. v0.5는 정보 페이지가 아니라 봉투 개봉부터 종이 조각의 움직임까지 하나의 경험으로 만드는 것이 목적이며, 버전 요구 사항에서 React, TailwindCSS, Framer Motion을 명시했다.

## 결정

- v0.5 전용 렌더러에만 React와 Framer Motion을 사용한다.
- TailwindCSS는 v0.5 스타일 진입점에서만 불러온다.
- v0.4의 DOM 렌더러와 스코프된 CSS는 수정하지 않는다.
- v0.5는 `/v0.5/` 독립 경로와 전용 이미지 폴더를 가진다.
- 첫 화면은 봉투를 열기 전까지 스크롤을 잠그고, 개봉 애니메이션 뒤에 브로슈어를 시작한다.
- 다음 버전의 번호, 제목, 내용은 공개 코드와 화면에서 밝히지 않는다.

## 결과

최신 버전은 더 큰 런타임 번들을 갖지만, 과거 버전에 영향을 주지 않는다. 각 버전이 공개 당시 선택한 기술과 표현을 함께 보존한다는 프로젝트 목적에도 부합한다.
