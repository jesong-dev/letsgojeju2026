# Roadmap

버전 번호는 기능의 양보다 여행 준비 과정의 의미 있는 공개 시점을 나타냅니다.

## v0.4 — 숙소 결정

- 상태: 공개
- 여행 날짜와 숙소 확정
- 공개 브로슈어의 시각적 분위기 확립

## v0.5 — 10월의 제주

- 상태: 공개
- 제주에서 온 편지를 여는 인터랙티브 브로슈어
- 10월 제주의 계절감과 여행 키워드
- 스크랩북, 폴라로이드, 여행 티켓의 디자인 언어

## v0.6 — 제주에서 작은 메모가 도착했습니다

- 상태: 공개
- 여행 정보를 설명하지 않고 두 장의 짧은 메모로 호기심과 기대감 전달
- 여행자의 책상 위에서 봉투 덮개와 메모를 직접 당겨 발견하는 경험
- 첫 메모 뒤에 남은 두 번째 메모를 순차적으로 꺼내는 흐름
- 종이 질감, 사용감 있는 봉투, 여행 노트와 수하물 태그로 구성한 물리적 무대
- 키보드 조작과 모션 감소 환경 지원

## 다음 장

- 상태: 비공개
- 정확한 공개 일정은 정하지 않는다.
- 여행이 조금 더 가까워졌을 때 다음 메모를 공개한다.
- 제목, 번호와 구체적인 여행 내용은 준비가 끝날 때까지 공개하지 않는다.
