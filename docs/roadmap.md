# Roadmap

버전 번호는 기능의 양보다 여행 준비 과정의 의미 있는 공개 시점을 나타냅니다.

## v0.4 — 숙소 결정

- 상태: 공개
- 여행 날짜와 숙소 확정
- 공개 브로슈어의 시각적 분위기 확립

## v0.5 — 여행의 윤곽

- 상태: 계획
- 방문하고 싶은 장소와 음식 후보
- 이동 동선을 고려한 느슨한 일정
- v0.4와 다른 공개 당시 감정과 디자인 보존

## v0.6 — 예약과 이동

- 상태: 계획
- 항공·교통·예약 현황
- 꼭 확인할 준비 사항

## v0.7 — 함께 고른 제주

- 상태: 계획
- 동행자 의견이 반영된 최종 후보
- 선택에서 제외된 대안과 이유 기록

## v0.8 — 출발 전 브리핑

- 상태: 계획
- 확정 일정, 날씨 대응, 짐 목록
- 모바일에서 빠르게 확인하는 실용 정보

## v0.9 — 여행 직전

- 상태: 계획
- 마지막 변경 사항
- 기대하는 장면과 남기고 싶은 기록

## v1.0 — 실제 여행 기록

- 상태: 계획
- 실제 이동, 사진, 메모와 회고
- 계획 버전과 실제 경험 연결
- 전체 준비 과정에서 달라진 점 정리
