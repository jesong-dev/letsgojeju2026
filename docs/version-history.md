# Version History

공개 버전마다 아래 항목을 복사해 기록합니다.

## v0.4 — 축! 숙소 결정

- 공개일: 2026-07-09
- 목적: 여행 날짜와 숙소가 정해진 순간을 모바일 브로슈어로 알리기
- 핵심 감정: 설렘, 안도감, 함께 떠난다는 따뜻함
- 주요 변경 사항:
  - 별빛이 있는 어두운 배경과 세로형 숙소 카드 구성
  - 비행기 아이콘 왕복 애니메이션
  - 최종 여행 날짜와 숙소 결정 상태 표시
- 고민했던 대안:
  - Editorial, Pastel, Dark Minimal, Typography 시안
  - 날짜 선택 폼과 Firebase 응답 수집 방식
- 최종 결정:
  - 상호작용을 줄이고 결정된 날짜와 숙소 이미지에 집중
  - 공개본은 독립 경로 `/v0.4/`에서 보존
- 다음 버전 계획:
  - 세부 일정과 방문 후보지를 정리하는 v0.5

> 공개일은 기존 파일의 최종 수정일(2026-07-09)을 기준으로 기록했다. 실제 공개일이 다르면 registry와 이 문서를 함께 수정한다.

## v0.5 — 10월의 제주

- 공개일: 2026-07-31
- 목적: 정보를 탐색하는 사이트가 아니라, 제주에서 온 여행 편지를 직접 여는 경험 만들기
- 핵심 감정: 기다림, 따뜻함, 장난스러운 호기심, 함께 만드는 기억
- 주요 변경 사항:
  - 봉투 개봉을 중심으로 한 첫 화면과 스크롤 해제 인터랙션
  - 편지, 폴라로이드, 여행 티켓, 손그림, 스탬프 디자인 언어
  - 10월 제주 노트와 여행 키워드
  - 0.5만 강조하는 여정 진행도
  - 열리지 않는 마지막 비밀 봉투
- 고민했던 대안:
  - 컨셉 아트의 화면 배치를 직접 복제하는 방식
  - 일반적인 히어로와 정보 카드 구성
- 최종 결정:
  - 컨셉 아트는 브랜드 무드만 참고하고 데스크톱 스크랩북 흐름으로 재해석
  - v0.4와 독립된 React·TailwindCSS·Framer Motion 화면으로 보존
  - 다음 버전의 내용과 번호는 비밀 봉투 안에서 공개하지 않음
- 다음 버전 계획:
  - 비공개

## v0.6 — 제주에서 작은 메모가 도착했습니다

- 공개일: 2026-08-28
- 목적: 여행의 정답을 공개하지 않고, 두 장의 짧은 메모로 호기심과 기대감 만들기
- 핵심 감정: 궁금함, 기대감, 상상, 기다림
- 주요 변경 사항:
  - 닫힌 봉투를 열고 Memo 01과 Memo 02를 직접 차례로 당겨 꺼내는 인터랙션
  - 첫 메모 뒤에 다른 색 테이프와 "한 장 더 있습니다." 안내로 두 번째 메모 존재를 명확히 표현
  - 두 메모를 꺼낸 뒤 세로 스크롤로 종이 위 내용을 읽는 단일 페이지 구성
  - 키보드 Enter/Space 조작, 모션 감소 환경, 손글씨 대체 글꼴 지원
- 고민했던 대안:
  - 두 메모를 한꺼번에 공개하는 방식
  - 컨셉아트의 돌고래와 밤하늘 사진을 그대로 사용하는 방식
- 최종 결정:
  - 사용자가 각 메모를 직접 꺼내며 발견의 속도를 조절하도록 구성
  - 별, 돌고래 사진, 밤하늘은 제외하고 여행 노트, 낮의 사진, 수하물 태그처럼 의미를 확정하지 않는 흔적만 유지
  - 재방문 때도 닫힌 봉투에서 시작하고, 소리·진동·공개 일정은 제공하지 않음
- 다음 버전 계획:
  - 공개 일정 미정

## v0.7 — 여행의 첫 번째 선택

- 공개일: 2026-09-02
- 목적: 사용자가 작은 선택 하나를 하며 여행을 조금 시작했다고 느끼게 만들기
- 핵심 감정: 발견, 참여, 가벼운 웃음, 가까워진 여행
- 주요 변경 사항:
  - 봉투 안에서 접힌 제주 지도를 발견하고 펼치는 3단계 상호작용
  - 제주공항을 중심으로 도보, 버스, 택시 중 시작 방법 하나를 선택하는 경험
  - 선택에 따라 다른 속도의 짧은 이동선 표시
  - v0.6 메모 컴포넌트를 재사용해 이전에 받은 문장의 의미를 여행의 시작에서 다시 만나는 연출
  - 이동 중 메모 윗부분이 먼저 보이고 같은 종이가 끊김 없이 올라오는 전환
  - 상세 지도, 관광지, 목적지, 거리, 시간과 비용 정보는 제공하지 않음
  - 키보드 조작과 모션 감소 환경 지원
- 고민했던 대안:
  - 실제 제주 지도와 도로를 사용하는 방식
  - 각 교통수단의 장단점을 비교하는 정보형 화면
- 최종 결정:
  - 지도는 제주를 암시하는 종이 위 추상 선으로만 표현
  - 선택의 효율을 비교하지 않고 여행을 시작하는 기분만 다르게 전달
  - 선택을 다시 바꿔볼 수 있으며, 이동선과 메모를 보고 경험이 끝나는 30초 이내 흐름
- 다음 버전 계획:
  - 비공개
