# Let's Jeju 2026
## UX Direction v0.7

### Theme

여행은 출발하는 날 시작되지 않습니다.
기다리는 시간도 여행의 일부입니다.

이번 버전은
사용자가 처음으로 여행에 참여하는 버전입니다.

지금까지는
제주가 이야기를 들려주었습니다.

이번에는
사용자가 작은 선택 하나를 하며
여행을 시작합니다.

---

### Goal

사용자가

"정보를 얻었다."

가 아니라

"내가 여행을 조금 시작했다."

라는 감정을 느끼게 합니다.

---

### Important

이 페이지는

여행 정보 페이지가 아닙니다.

교통편 안내 페이지도 아닙니다.

게임도 아닙니다.

사용자가
30초 정도 머물며

가볍게 웃고

여행이 조금 가까워졌다고 느끼면 성공입니다.

---

### Design Principle

- 선택은 최소
- 결과는 짧게
- 정보보다 감정
- 설명보다 발견
- 여행 준비도 여행입니다.
