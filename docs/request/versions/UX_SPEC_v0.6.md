# 확정된 구현 결정

- 최초 방문과 재방문 모두 닫힌 봉투에서 시작한다.
- 화면에는 "제주에서 작은 메모가 도착했습니다."와 "봉투를 열어보세요." 안내를 표시한다.
- 봉투 덮개는 자동으로 재생하지 않는다. 사용자가 덮개를 직접 위로 당기는 만큼 열리며, 충분히 열면 Memo 01의 일부가 나타난다.
- 사용자가 Memo 01을 직접 위로 당겨 꺼내야 내용을 확인할 수 있다.
- Memo 01을 꺼낸 뒤에는 봉투 안에 Memo 02의 종이 모서리와 다른 색 마스킹테이프를 노출한다.
- "한 장 더 있습니다."라는 작은 손글씨와 미세한 움직임으로 Memo 02가 남아 있음을 분명히 알린다.
- 사용자가 Memo 02도 별도로 위로 당겨 꺼낸다.
- 두 메모를 모두 꺼내면 순서대로 놓인 상태에서 경험이 끝난다. 봉투는 다시 닫히지 않는다.
- 모바일에서는 세로 스크롤을 허용한다.
- 다음 메모의 정확한 공개 일정이나 카운트다운은 표시하지 않는다.
- 소리와 진동 효과는 사용하지 않는다.
- 컨셉아트의 별, 돌고래 사진, 밤하늘 이미지는 사용하지 않는다.
- 꽃, 귤, 종이비행기와 낮의 하늘·바다 이미지는 분위기를 암시하는 장식으로 사용할 수 있다.
- 키보드 사용자는 봉투, Memo 01, Memo 02를 순서대로 포커스하고 Enter 또는 Space로 조작할 수 있어야 한다.
- `prefers-reduced-motion` 환경에서는 흔들림과 이동 애니메이션 없이 상태 변화와 안내 문구만으로 같은 정보를 전달한다.
- 손글씨 글꼴을 사용할 수 없는 환경에서도 읽을 수 있는 대체 글꼴을 제공한다.
